# JavaScript Number Guessing Game

A simple, interactive number guessing game I built while learning the fundamentals of JavaScript.

## About

This project was created to practice connecting JavaScript with HTML and CSS. The goal was to learn how JavaScript can evaluate user input, apply game logic, and dynamically update elements on a webpage based on those interactions.

## What I Learned

While building this project, I practiced:

* Using JavaScript variables and conditional logic (if/else statements)
* Generating random numbers with `Math.random()`
* Working with the DOM (Document Object Model)
* Adding event listeners for user inputs and button clicks
* Validating form input (preventing numbers outside the 1-100 range)
* Using `setTimeout` and `clearTimeout` to control UI animations
* Updating HTML content and CSS styling dynamically with JavaScript
* Organizing a project into separate HTML, CSS, and JavaScript files

## Features

* **Interactive Guessing** — evaluates user input against a randomly generated secret number
* **Dynamic Feedback** — provides on-screen hints (too high, too low) and changes text colors based on the guess
* **Input Validation** — restricts the textbox to only accept numbers between 1 and 100
* **Smooth UI Transitions** — features an introductory screen and uses timers to fade notifications in and out seamlessly

## Programming language Used

* HTML
* CSS
* JavaScript

## Purpose
Coming from a Java background, this project was my way of bridging the gap into JavaScript and web development. While I used tutorials and modern developer tools to help me navigate JavaScript's event-driven syntax and DOM manipulation, I wrote and debugged the core game logic myself to build genuine, hands-on experience.

I plan to continue building more projects as I learn additional JavaScript concepts and web development skills.
